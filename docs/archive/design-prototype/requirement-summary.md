## 一、五要素（Surface / Audience / Tone / Brand / Scale）

| 维度 | 结论 | 关键理由 |
|------|------|----------|
| **场景 Surface** | macOS 桌面 App 界面原型（非网页/移动端）：单窗口、HSplitView 双栏，左侧窄 sidebar（100–140px）承载 3 个 Tab，右侧 detail 区按 Tab 切换多状态。最小窗口 880×560。交付物为 HTML/CSS 高保真原型（作为 SwiftUI 实现蓝图），不是可运行 App。 | 用户明确要"重做 App 界面"，交付参照蓝图而非直接改 Swift。原型必须还原 macOS 原生窗口质感（标题栏、毛玻璃、SF Symbol、San Francisco 字体），并在此骨架上做"更高级"的精致度提升。 |
| **受众 Audience** | Mac 进阶用户 / 开发者。技术向、注重精确与可信；对"误删"零容忍；关心彻底清理与残留痕迹。审美上偏好克制、专业、可靠的工具质感，能接受信息密度（扫描器数、路径、体积、风险标签）。 | 产品卖点是"16 类痕迹 + 14 扫描器 + 沙箱"与"安全模型"，目标人群是会用 CLI、读路径、查 bundle id 的人。UI 应服务"精确与可信"而非消费级花哨。 |
| **调性 Tone** | **推荐方向：克制、精密、可信、略带专业工具的高级感**——视觉上应传达"这是一台值得信任的精密仪器"。参考学派以 **Modern Minimal** 为基底，融合 **Tech Utility** 的数据精确感（路径/体积等机器数据用等宽字体）。具体明暗/质感取向列为下方待确认项 Q1。 | 调性必须呼应产品灵魂"安全模型"：诚实报账、白名单硬阻断、用户数据默认保护。克制不等于简陋——精密感来自对齐网格、清晰层级与可信的色彩语义。 |
| **品牌上下文 Brand** | 现状：无独立品牌系统（开源项目，GitHub 主页即品牌载体），无强制配色/logo 规范。**风险语义色已约定且必须保留**：用户数据=橙、不确定=黄、安全=灰；确认弹窗橙色警告须保留。**建议**：是否建立一套极简品牌强调色（用于主操作"移到废纸篓"与品牌点缀），见待确认项 Q2。 | 开源项目无既有约束，是建立轻量品牌资产的好时机；但风险标签语义是功能正确性的一部分，不可随意改动。 |
| **规模 Scale** | 3 个主屏（扫描 / 残留 / 历史）+ 2 个弹窗（ConfirmSheet / ResultSheet）+ 左侧 sidebar。单窗口多状态：扫描 Tab 含空状态/扫描中/结果态三种；残留 Tab 含未扫描/扫描后两种；历史含空/列表。复杂度：以静态高保真为主，建议含轻量交互态（hover、勾选、列表折叠、弹窗叠加、Tab 切换）与状态示意；动效作加分项，非必需。 | 范围已由现有结构锚定，无需重新设计功能，只需在视觉与信息层级上做高品质重做。 |

## 二、待确认项（需用户最终拍板）

> 以下以问答形式列出，便于主理人直接转交用户确认。最关键的是 **Q1 视觉调性/明暗取向**。

**Q1（最关键 — 视觉调性 / 明暗取向）：整体视觉方向你倾向哪一种？**
- A. **明亮通透** — 浅色窗口、大留白、清爽专业，最贴近原生 macOS 默认观感，普适且显"大气"。
- B. **深色沉稳** — 深色窗口、低亮度、开发者友好、专注感强，信息密度场景更耐看。
- C. **双主题** — 同时交付浅色 + 深色两套配色（原型阶段工作量更大，但最稳妥）。
- D. **拟物 / 质感** — 轻微材质层次与柔和阴影，强调工具"实体感"。

**Q2（品牌色）：是否要为 AI Mac Cleaner 建立一套极简品牌强调色？**
- A. 不需要，沿用系统蓝 + 既有风险语义色即可。
- B. 需要，建议一个"可信"强调色（如沉静蓝 / 青 / 琥珀）用于主操作与品牌点缀。
- C. 需要，但由设计方先提案、用户再从中选择。

**Q3（原型交互深度）：原型需要做到哪种交互程度？**
- A. 纯静态高保真 — 所有状态"截图式"呈现（空 / 扫描中 / 结果 / 弹窗各一版）。
- B. 轻交互 — 可点击 Tab、勾选、弹窗开关、列表折叠（无真实逻辑）。
- C. 含动效 — 加载进度、状态过渡动画等（最显"高保真"，但耗时最多）。

## 三、设计机会点（最易做出"美观大气"改观的位置）

在保持功能完整的前提下，以下 5 处是性价比最高的视觉升级抓手：

1. **窗口级留白与节奏**：当前功能密集，适度放大 padding、统一 8px 网格、规范分组间距，让"精密感"不变成"拥挤感"。
2. **分组卡片化**：16 类残留项、反向扫描分组用柔和卡片 / 分区条替代纯列表，显著提升可读性与层级。
3. **风险可视化升级**：把风险标签做成精致的 pill / 徽章，配合图标与微动效——把"安全模型"从隐藏规则变成**可见的信任资产**。
4. **状态反馈与动效**：扫描进度、空状态引导、结果三态（红/橙/绿）用克制的动效与色彩传递"确定感"。
5. **确认弹窗的信任感（最该被放大的灵魂）**：把"诚实报账"文案、可复制路径列表、用户数据专项提醒，做成排版精致、层级清晰、**让人安心而非焦虑**的确认体验——这是产品价值观最该被设计放大的地方。
