### 字体策略说明

原型未下载任何网络字体，使用纯系统字体栈：

- **UI 字体**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", …`

## 六、二次开发提示

若需在此原型基础上继续开发：

1. **改样式先改 token**——所有颜色 / 字号 / 间距 / 圆角 / 阴影集中定义在 `<style>` 开头的 `:root` 块中，与 `design-tokens.md` 一一对应。改 `:root` 变量即可全局换肤，不要散改具体规则。
2. **加图标**——在 `<svg id="sprite">` 内新增 `<symbol id="i-xxx" viewBox="0 0 24 24">`，然后用 `<svg class="ic ic-12"><use href="#i-xxx"/></svg>` 引用，保持零外链原则。
3. **接真实数据**——JS 底部的 `syncAll()` 为初始化入口，选中态与统计联动逻辑集中在此，替换数据源时从这里切入。
